# Data Model

## Core entities

### Person

Представляет исследуемого человека.

Основные поля:

- id;
- name / pseudonym;
- category;
- birth year или age range;
- geography;
- source references;
- metadata.

Для чувствительных данных должна поддерживаться анонимизация.

### Observation

Наблюдение значения переменной в определённый момент времени.

```text
person_id
variable_id
timestamp
value
unit
source
confidence
```

### Event

Событие жизненной или профессиональной траектории.

Примеры:

- образование;
- начало бизнеса;
- запуск продукта;
- соревнование;
- травма;
- смена команды;
- инвестиция;
- карьерный переход.

### Habit

Повторяющееся поведение.

Примеры:

- сон;
- тренировки;
- обучение;
- чтение;
- рабочая нагрузка;
- восстановление.

### Achievement

Измеримый результат.

Примеры:

- доход;
- капитал;
- рейтинг;
- медаль;
- рекорд;
- должность;
- количество компаний.

### Dataset

Набор наблюдений, используемый исследованием.

Dataset должен иметь версию.

### Study

Описание конкретного исследования:

- вопрос;
- гипотеза;
- population;
- dataset;
- variables;
- methods;
- assumptions;
- results;
- limitations.

### Model

Статистическая или сценарная модель.

### Scenario

Набор предполагаемых условий для моделирования альтернативной траектории.

### Trajectory

Упорядоченная временная последовательность наблюдений, событий и результатов.

### Report

Воспроизводимый документ исследования.

## Единицы измерения

Все количественные значения должны иметь явную единицу.

Например:

```
hours/week
hours/day
EUR
USD
kg
cm
years
points
percent
ratio
```

Нельзя хранить число без семантики единицы.

## Missing data

Отсутствующие данные не должны автоматически превращаться в ноль.

Поддерживать состояния:

- observed;
- missing;
- not applicable;
- estimated;
- censored.

## Provenance

Для важных данных хранить происхождение:

- source;
- source date;
- extraction method;
- confidence;
- manual/automatic flag.

## Versioning

Изменение исходных данных должно создавать новую версию Dataset, чтобы старые результаты исследования оставались воспроизводимыми.
