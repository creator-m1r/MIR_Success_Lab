# Methodology

## Основной принцип

MIR Success Lab — аналитическая система, а не система гарантированного предсказания человеческой судьбы.

Она исследует наблюдаемые данные и строит условные модели.

## 1. Correlation ≠ causation

Если фактор X статистически связан с результатом Y, система не должна автоматически формулировать:

> X вызывает Y.

Интерфейс и отчёты должны различать:

- association;
- prediction;
- causal evidence.

## 2. Selection bias

При анализе успешных людей необходимо учитывать, что выборка может быть сформирована уже после достижения результата.

Особенно важно не делать выводы только на основании известных успешных людей.

## 3. Survivorship bias

Система должна по возможности сравнивать успешные траектории с соответствующими контрольными или альтернативными траекториями.

## 4. Temporal ordering

При исследовании поведения фактор должен быть связан с правильным моментом времени.

Фактор, возникший после достижения результата, нельзя без дополнительного анализа считать его предшествующей причиной.

## 5. Confounders

Исследования должны позволять указывать потенциальные смешивающие факторы:

- возраст;
- образование;
- страна;
- доход;
- отрасль;
- доступные ресурсы;
- здоровье;
- внешняя среда;
- период времени.

## 6. Uncertainty

Результаты должны сопровождаться подходящими показателями неопределённости:

- confidence intervals;
- prediction intervals;
- sample size;
- standard errors;
- model fit;
- sensitivity analysis.

## 7. Scenario modeling

Сценарии 5/10/15 лет являются условными моделями.

Формат результата:

```
условия
→ модель
→ распределение возможных результатов
→ диапазон
→ ограничения
```

Не следует показывать единичное число как гарантированный будущий результат.

## 8. Reproducibility

Любой результат должен быть повторяемым по сохранённым:

- dataset;
- parameters;
- random seed;
- algorithm version;
- preprocessing;
- model configuration.

## 9. Research workflow

```
Question
 ↓
Hypothesis
 ↓
Dataset
 ↓
Cleaning
 ↓
Exploration
 ↓
Statistical analysis
 ↓
Validation
 ↓
Scenario analysis
 ↓
Interpretation
 ↓
Report
```

## 10. Human interpretation

Программа может находить статистические паттерны, но окончательная интерпретация должна учитывать качество данных, дизайн исследования и ограничения модели.
