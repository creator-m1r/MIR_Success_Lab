# MIR Success Lab

**MIR Success Lab** — macOS-платформа для статистического исследования человеческих траекторий, поведения, привычек, профессиональных результатов и факторов, связанных с достижением целей.

Проект предназначен для предпринимателей, спортсменов и в дальнейшем для других профессиональных групп.

## Главная идея

Система собирает и сопоставляет наблюдаемые данные о людях во времени, выявляет повторяющиеся статистические паттерны, сравнивает группы, строит модели и позволяет исследовать сценарии развития на горизонте **5, 10 и 15 лет**.

> Важный принцип: статистическая связь не является доказательством причинности. MIR Success Lab должна показывать данные, неопределённость, ограничения моделей и качество выборки, а не обещать человеку гарантированный результат.

## Цели

- исследование биографических и поведенческих данных;
- сравнение успешных и контрольных групп;
- анализ привычек, решений, ресурсов и результатов;
- поиск повторяющихся траекторий;
- кластеризация похожих профилей;
- статистическое моделирование;
- сценарный анализ «что если»;
- визуализация 5/10/15-летних траекторий;
- автоматическая подготовка исследовательских отчётов;
- локальная работа с данными пользователя.

## Технологический стек

- **macOS**
- **Swift / SwiftUI** — пользовательский интерфейс и application layer;
- **C++26** — аналитическое и математическое ядро;
- **SQLite** — локальное хранилище;
- **Swift Charts / native macOS visualization** — визуализация;
- CSV / JSON — импорт и экспорт;
- PDF / HTML / Markdown — отчёты.

## Архитектурный принцип

```
SwiftUI
   ↓
Application Layer
   ↓
Analytics API
   ↓
MIR Analytics Engine (C++26)
   ↓
SQLite / Dataset Layer
```

UI не должен содержать математическую логику. Статистические расчёты, модели, валидация и сценарные вычисления находятся в C++26.

## Основные направления анализа

### Описательная статистика
Средние, медианы, квантили, дисперсии, стандартные отклонения, распределения, выбросы.

### Сравнение групп
Сравнение нескольких групп по выбранным признакам с указанием размера выборки и статистической неопределённости.

### Корреляционный анализ
Pearson, Spearman и другие методы при соответствующей структуре данных.

### Регрессионный анализ
Линейные и нелинейные модели, включая многомерные модели.

### Временной анализ
Изменения показателей во времени, события, переходы и карьерные траектории.

### Кластеризация
Поиск групп людей с похожими профилями и траекториями.

### Similarity
Поиск исторически похожих профилей по выбранному набору признаков.

### Scenario Lab
Сравнение базового профиля с альтернативными наборами условий.

### Monte Carlo
Оценка распределения возможных результатов при заданных предположениях и неопределённости.

## Научный принцип

Каждое исследование должно хранить:

1. исходный dataset;
2. описание выборки;
3. определения переменных;
4. методы очистки;
5. применённые методы анализа;
6. параметры моделей;
7. результаты;
8. метрики качества;
9. ограничения;
10. версию алгоритмов.

Это позволяет воспроизводить исследования.
